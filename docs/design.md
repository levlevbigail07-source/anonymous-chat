# 設計決定(需求訪談結果)

這份文件記錄跟使用者一問一答確定下來的「使用者會看到什麼、會做什麼」。
技術選擇(語言、框架、Supabase 功能、金鑰)不在這裡,由 `docs/architecture.md` 決定。
視覺設計(顏色、字型、版面細節)由 /design 負責,這裡只定風格方向與行為。

## 已確定

| # | 主題 | 決定 |
|---|------|------|
| Q1 | 歷史訊息 | 新加入的人看得到最近 50 則;訊息會被存起來,全部人離開後仍保留 |
| Q2 | 代號重複 | 讓他進來,系統自動加編號,例如「小明」→「小明#2」 |
| Q3 | 長度限制 | 代號最多 12 字、訊息最多 200 字。代號可用中文、英文、數字、表情符號,不可空白。超過時輸入框顯示還能輸入幾個字,並且不讓繼續打。空白訊息送不出去 |
| Q4 | 自己斷線 | 頂端顯示「連線中斷,重新連線中…」,輸入框暫時不能送出。恢復後提示消失,自動補上錯過的訊息,代號不變。10 秒內恢復的短暫斷線不通知大家;超過 30 秒才算離開,大家看到「某某 離開了」 |
| Q5 | 在線名單 | 電腦版:名單固定在右側。手機版:不顯示名單,只在頂端顯示人數 |
| Q6 | 訊息顯示 | 每則顯示代號、內容、時間(如 14:32)。自己的訊息靠右、別人靠左。進入/離開提示是置中小字。新訊息來時:在最底下就自動捲到最新;正在往上翻則不亂動,下方出現「有 N 則新訊息 ↓」按鈕,點了才跳到底 |
| Q7 | 額外功能 | 只做「新訊息時網頁標題閃爍」(切到別的分頁時,標題變成「(2) 匿名聊天室」)。不做提示音、防洗版、網址可點擊、輸入中提示、圖片檔案、編輯刪除、私訊 |
| Q8 | 風格 | 跟著手機或電腦的深色/淺色模式自動切換;手機優先 |

| Q9 | 不當內容 | 做「檢舉」:每則別人的訊息旁有「檢舉」按鈕,按了之後管理者到後台看得到。不做敏感字過濾。管理者到 Supabase 後台手動刪除訊息。首頁加一行小字:「這是匿名聊天室,訊息會保留最近 50 則,請勿發布個人資料」(小字為建議預設,使用者未特別修改) |

檢舉的細節(尚未問使用者,由架構文件決定並說明):自己的訊息不顯示檢舉按鈕;按下後顯示「已檢舉」確認;同一人對同一則訊息只算一次。

## 字型與圖示

- 字型:`'PingFang TC','Noto Sans TC','Microsoft JhengHei',system-ui,sans-serif`(系統字型,不載入外部字型)
- 大小:首頁標題 32px、聊天室標題 18px(電腦 20px)、訊息內文 16px、代號 13px、時間與小提示 12 到 13px
- 圖示:全部是行內 SVG 線條圖示(對話框、紙飛機、旗子、勾、重新整理、向下箭頭),不用 emoji 當圖示
- 輸入框字級至少 16px(避免 iPhone 輸入時自動放大畫面)

## 版面規格

- 首頁:單欄置中,左右留白 24px;輸入框與按鈕高 52px、圓角 12px;提醒小字固定在底部
- 聊天室(手機):由上到下是標題列、(斷線提示條)、訊息區、輸入區;標題列右側是「N 人在線」膠囊,左側是名稱
- 聊天室(電腦):標題列在上;下方左邊是訊息區加輸入區,右邊固定寬 260px 的在線名單;訊息氣泡最寬 62%(手機 82%)
- 訊息氣泡:圓角 16px,靠發話者那一側的下角改 4px;自己靠右、藍底白字、不顯示代號;別人靠左、有邊線、上方顯示代號
- 輸入框圓角 24px、高 48px;送出在手機是圓形圖示按鈕,在電腦是「送出」加圖示的文字按鈕
- 訊息區新訊息自動貼底,內容不足時從底部開始排

## 元素與狀態

| 元素 | 設計細節 |
|------|----------|
| 進出提示 | 置中、13px、次要文字色,例如「小華 進來了」 |
| 檢舉按鈕 | 只在別人的訊息時間旁;旗子圖示加「檢舉」,12px、次要文字色;`aria-label` 帶上對方代號 |
| 已檢舉 | 檢舉按鈕換成綠色勾加「已檢舉」,不能再按 |
| 斷線提示條 | 標題列下方整條橫幅、警示色、重新整理圖示、文字「連線中斷,重新連線中…」;`role="status"` |
| 斷線時的輸入區 | 輸入框與送出按鈕停用變灰,placeholder 改為「連線中斷,暫時無法送出」 |
| 新訊息按鈕 | 懸浮在輸入區上方正中央、膠囊形、主色底、「有 N 則新訊息 ↓」、至少 44px 高 |
| 字數提示 | 輸入框下方靠右、12px,「還能輸入 N 字」 |
| 代號錯誤 | 輸入框改為 2px 錯誤色邊框,下方左側顯示錯誤文字(`role="alert"`),右側仍顯示剩餘字數 |
| 在線名單(電腦) | 標題「在線(N)」;每人前有綠色圓點;自己排第一、有底色、右側「你」標籤 |
| 網頁標題 | 背景時有新訊息:`(N) 匿名聊天室`,回到前景恢復成 `匿名聊天室` |

## 無障礙

- 所有按鈕用真的 `<button>`,輸入框都有對應的 `<label>`(聊天室輸入框的 label 是視覺隱藏)
- 僅有圖示的按鈕要有 `aria-label`(例如送出)
- 文字對比至少 4.5:1;兩種模式都要檢查
- 可點擊目標至少 44px 高(檢舉按鈕的視覺較小,點擊範圍要補到 44px)

## 做前端時的提醒

- 設計稿裡的人名與訊息只是示意,**不要寫死**;資料來自通訊層(見架構文件第 4、5 節)
- 設計稿沒有畫的情況,請沿用相同風格並回報:歷史訊息載入中、完全沒有訊息時的空狀態、很多人在線時名單過長(建議名單區自己捲動)、單一長字串不換行(要設定自動換行)
- 手機版輸入區要避開 iPhone 底部橫條(`env(safe-area-inset-bottom)`)
